# 用户故事与完成定义

## 1. 角色

- 营销与产品人员：为落地页、EDM、产品更新和帮助内容制作短动效。
- 产品设计与研发人员：快速录制 Web 产品流程、局部交互或跨应用操作。
- 本地优先用户：希望素材不上传云端，并能在浏览器内反复编辑和导出。
- 发布验证人员：需要可重复、可审计地判断一个扩展版本是否可发布。

## 2. 用户故事

### US-01 首次安装与价值理解

作为首次使用者，我希望安装后能快速理解扩展做什么、数据在哪里处理，以及如何开始第一次录制，从而无需阅读外部文档。

- 优先级：P1
- 当前完成定义：Welcome 可访问；价值、隐私和主格式陈述与实际能力一致；用户可从 Welcome 发起第一次标准录制。

### US-02 选择正确的标准录制来源

作为内容创作者，我希望录制当前标签页、某个窗口或整个屏幕，从而按任务范围获得正确画面。

- 优先级：P0
- 当前完成定义：三种来源入口可理解；Picker 取消可恢复；最终记录的来源尺寸与用户选择一致。

### US-03 录制面向 GIF 的页面区域

作为营销人员，我希望从 Action 直接选择“GIF 录制”、框选页面区域并录制动态内容，从而减少无关像素和 GIF 体积。

- 优先级：P0
- 当前完成定义：入口具备按钮可点击感；选区可确认、取消和重选；坐标在 DPR/页面缩放下正确；录制固定视口区域；结果进入 Studio 且保留 GIF intent。

### US-04 安全控制录制会话

作为录制者，我希望倒计时、暂停、恢复和停止在 Popup 关闭或后台休眠后仍可靠，从而不会丢失会话或产生重复文件。

- 优先级：P0
- 当前完成定义：会话单一所有权；状态可恢复；暂停时间不计入 active duration；Stop/finalize 幂等；并发启动被拒绝。

### US-05 自动进入正确的 Studio 录制

作为录制者，我希望停止后自动打开对应录制的 Studio，从而无需手动寻找刚生成的素材。

- 优先级：P0
- 当前完成定义：打开的 recording ID 唯一且正确；GIF intent 从会话/OPFS 传入；失败时不会打开空白或错误录制。

### US-06 可靠预览与定位

作为编辑者，我希望 Studio 中的画面、播放时钟和 Seek 始终对应真实媒体时间，从而能判断录制是否有效并精确编辑。

- 优先级：P0
- 当前完成定义：首帧可见；动态画面真实变化；静态段时钟继续；快速 Seek 与跨读取窗口不会被旧帧覆盖。

### US-07 修剪时间与强调重点

作为编辑者，我希望删除多余首尾并添加聚焦/缩放，从而快速得到紧凑、易理解的产品演示。

- 优先级：P0
- 当前完成定义：Trim 使用明确半开区间；Focus/Zoom 时序连续；重新打开编辑器时配置不意外丢失；导出与预览一致。

### US-08 调整构图与品牌呈现

作为内容创作者，我希望设置比例、Crop、背景、内边距、圆角和阴影，从而生成适合落地页或邮件版式的成品。

- 优先级：P1
- 当前完成定义：所有控制可组合；预览无拉伸/黑边；上传背景仍保存在本地；重新编辑和导出保留效果。

### US-09 导出通用视频

作为内容创作者，我希望导出 MP4 或 WebM 并选择尺寸/帧率，从而嵌入网页或交付给其他工具。

- 优先级：P0
- 当前完成定义：格式签名、显示尺寸、时长和编辑效果正确；取消/失败可重试且不留下残缺文件。

### US-10 导出可交付的邮件 GIF

作为营销人员，我希望 GIF 工作流默认使用合理的邮件参数、显示体积风险并输出真正动态且结构有效的 GIF，从而用于 EDM 预览与交付。

- 优先级：P0
- 当前完成定义：默认 GIF、10 fps、适配 600px 的 scale、有限循环；产物包含至少两个视觉不同帧；Trailer 有效；实际体积与 UI 风险等级一致；超内存预算时安全失败。

### US-11 管理本地录制

作为重复使用者，我希望查看、打开和删除本地录制，并识别未完成素材，从而管理浏览器占用空间。

- 优先级：P0
- 当前完成定义：列表与 OPFS 一致；打开精确录制；单个/批量删除需确认；残缺目录不会导致 Manager 崩溃。

### US-12 从失败、重载和升级中恢复

作为用户，我希望 Picker 取消、来源结束、Worker/Service Worker 重启、扩展升级或旧录制数据不会让我陷入不可恢复状态。

- 优先级：P0
- 当前完成定义：错误可理解且可重试；旧 operation 不覆盖新会话；旧录制可打开或明确说明不兼容；升级不误删 OPFS 数据。

### US-13 信任本地优先和权限边界

作为重视隐私的用户，我希望录制、编辑和导出默认不上传，并且扩展只请求完成任务所需权限，从而信任产品声明。

- 优先级：P0
- 当前完成定义：主旅程没有媒体外传；Manifest 权限与功能一致；外部导航来自明确用户操作；发布文案不声明未实现的云能力。

### US-14 使用可访问且本地化的界面

作为键盘、辅助技术或非英语用户，我希望所有关键操作可聚焦、可理解且对比度足够，从而独立完成录制和导出。

- 优先级：P1
- 当前完成定义：Popup、选区、Studio、导出弹窗和 Manager 的键盘路径完整；对话框焦点受控；中英文主路径无缺失 key；窄宽度无横向溢出。

### US-15 在目标设备上稳定完成任务

作为普通设备用户，我希望 1080p 录制、预览和导出不会持续掉帧、无限增长内存或冻结页面，从而完成真实工作。

- 优先级：P1
- 当前完成定义：Balanced 1080p/30 满足实时预算；连续三轮旅程资源回到基线；长录制与低配 Windows 有明确证据。

## 3. 当前非目标

以下能力不进入当前 P0/P1 发布承诺，除非版本说明明确新增：

- 摄像头主持人、音频混录和字幕；
- 跟随 DOM 元素的智能录制；
- 多片段专业剪辑；
- 云托管、分享链接和分析；
- 自动生成完整 Landing Motion Pack；
- 保证所有邮件客户端播放动画，尤其只显示第一帧的客户端。
