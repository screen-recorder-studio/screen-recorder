把网页中的一个重点流程，直接变成清晰的 GIF 或视频——录制、编辑和导出都在 Chrome 本地完成，无需上传，也不用打开另一款剪辑软件。

只录真正重要的内容

• 在受支持的网页上框选区域，直接进入聚焦的 GIF 录制流程
• 也可录制浏览器标签页、应用窗口或整个屏幕
• 选定录制源后才开始倒计时，避免把系统选择窗口录入画面

在 Studio 中完成润色

每次录制完成后都会打开内置 Studio，您可以：

• 裁剪片段开头和结尾
• 精确裁切画面区域
• 添加平滑缩放和焦点位置
• 调整背景、边距、圆角和阴影
• 在导出前预览最终构图

面向邮件、网页和分享导出

• GIF：提供邮件导向的宽度、帧率和有限循环默认值，并在导出前显示体积估算与风险提示
• MP4（H.264）：适合广泛播放和分享
• WebM：适合高效的网页视频

短而聚焦的流程最适合 GIF。对于较长或画面变化较多的录制内容，可先在 Studio 中裁短片段或选择更轻量的输出设置。

本地优先，保护隐私

录制、编辑和导出均在 Chrome 本地运行。录制内容保存在浏览器的 Origin Private File System 中，并可从内置录制管理器重新打开。录制、编辑和导出流程不会把捕获的媒体上传到服务器。
