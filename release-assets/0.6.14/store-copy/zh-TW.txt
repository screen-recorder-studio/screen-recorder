把網頁中的一個重點流程，直接變成清楚的 GIF 或影片——錄製、編輯和匯出都在 Chrome 本機完成，無需上傳，也不用開啟另一款剪輯軟體。

只錄真正重要的內容

• 在支援的網頁上框選區域，直接進入聚焦的 GIF 錄製流程
• 也可錄製瀏覽器分頁、應用程式視窗或整個螢幕
• 選定錄製來源後才開始倒數，避免把系統選擇視窗錄入畫面

在 Studio 中完成潤飾

每次錄製完成後都會開啟內建 Studio，您可以：

• 裁剪片段開頭和結尾
• 精準裁切畫面區域
• 加入平滑縮放和焦點位置
• 調整背景、邊距、圓角和陰影
• 在匯出前預覽最終構圖

面向郵件、網頁和分享匯出

• GIF：提供郵件導向的寬度、影格率和有限循環預設值，並在匯出前顯示檔案大小估算與風險提示
• MP4（H.264）：適合廣泛播放和分享
• WebM：適合高效率的網頁影片

短而聚焦的流程最適合 GIF。對於較長或高動態內容，可先在 Studio 中裁短片段或選擇更輕量的輸出設定。

本機優先，保護隱私

錄製、編輯和匯出均在 Chrome 本機執行。錄製內容儲存在瀏覽器的 Origin Private File System 中，並可從內建錄製管理器重新開啟。錄製、編輯和匯出流程不會把擷取的媒體上傳到伺服器。

適合說清產品故事

• SaaS 功能發布和產品展示
• 客服支援與問題重現影片
• 技術文件和使用者導覽
• 設計原型展示
• 簡短教學和培訓片段

Screen Recorder Studio 採用 MIT 授權並開放原始碼。只錄重點，在 Studio 中完成潤飾，無需離開 Chrome 即可匯出標準檔案。
